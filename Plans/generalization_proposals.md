# Generalization Proposals

This file collects proposals for promoting observable-specific scripts written during individual measurements into central utilities shared across analyses. Entries are added at the end of each measurement by the agent.

The physicist reviews proposals and decides which to pursue. The agent does not generalize code unilaterally.

## Format

Each proposal follows this structure:

```
### [Date] — [Script name or function]
**What it does**: ...
**Currently lives in**: [repo/path]
**Why it should be central**: [which observables or analyses benefit]
**Changes needed to generalize**: [parameter names, interface, docs]
**Proposed home**: [central repo name]
**Status**: [Proposed / Under review / Approved / Implemented / Declined]
```
