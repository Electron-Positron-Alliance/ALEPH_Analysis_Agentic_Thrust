\section{Systematic uncertainties}
\label{sec:systematics}

Systematic variations are propagated by rerunning the full unfolding chain for each variation and comparing to the nominal unfolded result. The implementation uses:
\begin{itemize}
\item \texttt{run\_thrust\_prelim\_workflow.py} for branch execution;
\item \texttt{build\_prelim\_uncertainty\_summary.py} for component extraction and total combination.
\end{itemize}
For each source $v$, the signed bin-wise shift is
\begin{equation}
\delta_v(j)=\frac{U_v(j)-U_{\mathrm{nom}}(j)}{U_{\mathrm{nom}}(j)}.
\end{equation}

\subsection{Combination model for the nominal uncertainty}

For the nominal uncertainty used in the final result, the components are combined as
\begin{equation}
\Delta_{\mathrm{iter}}(j)=\max\left(|\delta_{\mathrm{iter4}}(j)|,|\delta_{\mathrm{iter6}}(j)|\right),
\end{equation}
\begin{equation}
\Delta_{\mathrm{track/event}}(j)=\sqrt{\sum_{v\in\{\mathrm{ntpc7,pt04,ech10,with\_met}\}} |\delta_v(j)|^2},
\end{equation}
\begin{equation}
\Delta_{\mathrm{neutral}}(j)=\sqrt{\max\left(|\delta_{\mathrm{nes\_up}}(j)|,|\delta_{\mathrm{nes\_down}}(j)|\right)^2 + |\delta_{\mathrm{ner}}(j)|^2},
\end{equation}
\begin{equation}
\Delta_{\mathrm{exp}}(j)=\sqrt{\Delta_{\mathrm{track/event}}^2(j)+\Delta_{\mathrm{neutral}}^2(j)},
\end{equation}
\begin{equation}
\Delta_{\mathrm{theory}}(j)=\max\left(|\delta_{\mathrm{pythia8}}(j)|,|\delta_{\mathrm{herwig}}(j)|,|\delta_{\mathrm{sherpa}}(j)|\right),
\end{equation}
with total bin uncertainty
\begin{equation}
\Delta_{\mathrm{tot}}(j)=\sqrt{\Delta_{\mathrm{stat}}^2(j)+\Delta_{\mathrm{iter}}^2(j)+\Delta_{\mathrm{exp}}^2(j)+\Delta_{\mathrm{theory}}^2(j)+\Delta_{\mathrm{had}}^2(j)},
\end{equation}
where $\Delta_{\mathrm{had}}$ is the hadronic event-selection correction uncertainty described in Sec.~\ref{sec:had_uncertainty} below.

\subsection{Hadronic event-selection correction uncertainty}
\label{sec:had_uncertainty}

After unfolding, a bin-wise hadronic event-selection correction $C_{\mathrm{had}}(j) = N_{\mathrm{genBefore}}(j)/N_{\mathrm{gen}}(j)$ is applied to account for the fraction of hadronic events that pass the generator-level selection (see Sec.~\ref{sec:method}). The uncertainty on this correction is propagated as an independent component $\Delta_{\mathrm{had}}$.

The correction ratio $C_{\mathrm{had}}(j)$ is computed from two generator-level histograms: \texttt{tgenBefore} (events passing hadronic selection) and \texttt{tgen} (all generated events). Statistical uncertainties on both histograms are propagated through the ratio using standard error propagation, yielding bin-wise up and down variations $C_{\mathrm{had}}^{\pm}(j)$. These variations are applied to the unfolded spectrum and normalized to the differential cross-section basis, producing up and down shifted spectra. The fractional hadronic correction uncertainty is then defined as the envelope:
\begin{equation}
\delta_{\mathrm{had}}^{\pm}(j) = \frac{U_j \cdot C_{\mathrm{had}}^{\pm}(j) / \int U \cdot C_{\mathrm{had}}^{\pm}\,dT}{U_j^{\mathrm{corr}}} - 1,
\end{equation}
with $\Delta_{\mathrm{had}}(j) = \max(|\delta_{\mathrm{had}}^{+}(j)|, |\delta_{\mathrm{had}}^{-}(j)|)$.

In the central range $0.60 \le T < 0.95$, the mean hadronic correction uncertainty is approximately $3.2\%$, making it the third-largest component after theory ($6.1\%$) and experimental ($3.3\%$). Its covariance is built with the same \texttt{template\_correlated} model applied to other non-statistical components. The computation is implemented in \texttt{compute\_hadronic\_correction\_fractional\_shift} in \texttt{build\_prelim\_uncertainty\_summary.py}; note that the correction histogram stored in the nominal ROOT file carries zero bin errors by design, as the uncertainty is derived externally by this function rather than through ROOT error propagation.

The \texttt{no\_neutrals} branch removes all calorimeter neutral objects from the event and recomputes thrust using charged tracks only. It is not a physical uncertainty but a stress-test of the analysis sensitivity to the neutral-particle contribution: a large shift indicates that the calorimeter response and neutral-hadron modeling significantly shape the thrust distribution, while a small shift would indicate robustness to neutral inputs. The observed central-range mean shift of approximately 23\% confirms that neutral objects are a leading input to thrust and that the calorimeter modeling must be well-controlled. Because this variation is not a physical uncertainty on the measurement (it tests a configuration the data do not correspond to), it is excluded from $\Delta_{\mathrm{tot}}$ and treated as a cross-check only.

The non-statistical covariance model is configurable in the summary builder. The current nominal release uses the \texttt{template\_correlated} option, where each non-statistical component covariance is built as
\begin{equation}
\mathrm{Cov}^{(c)}_{ij}=\Delta_c(i)\,\Delta_c(j)\,\rho^{\mathrm{stat}}_{ij},
\end{equation}
with $\rho^{\mathrm{stat}}_{ij}$ taken from the statistical unfolding covariance correlation template. This keeps component magnitudes tied to the measured per-bin shifts while avoiding a purely diagonal systematic-covariance approximation.

For cross-check studies, \texttt{diagonal} and \texttt{block} component models are available in the same script and can be selected by configuration.
